# Ecopunk demo resource rebuild — 29 October 2026

This pack rebuilds the assets generated by the current interactive demo: eight site selections (six distinct scene templates), scene/water meshes and representative states across the five anatomy scales and five exposed vertebrate presets. It contains **41 decoded mesh resources**, four generated textures, eight native reference PNGs, selected generator/Vibe sources, a resource inventory, native Q42 metadata and per-resource claim dossiers.

The browser still calls the native Rust builders through WASM; it does not admit this HMC as its project. Selected source files are included for editing/regeneration with the pinned repository and dependency environment. This is not a self-contained replacement for the full source workspace or a qualified Poet cooperative-authoring project.

Continuous controls are sampled at neutral/mid/end values, co-varied together; every possible slider combination is not exported. Aliases share a template deliberately; eight labels do not establish eight independently reconstructed places. Historic stored assets and the named flora/fauna catalogues are not all rendered by this demo and are not claimed individually rebuilt.

Film, open-world game and cartoon package acceptance are all **incomplete/unassessed**. Every resource dossier preserves catalogue `2026-10-24.2` and its 193 deliverable claims, with expanded part/state/clip/behaviour/scenario obligations still open. No automated generation step awarded human or scientific acceptance. There is no complete accepted species embodiment in this pack.

The terrain and anatomy remain illustrative. ELVIS is identified as a source for the next terrain upgrade; no ELVIS-derived terrain or diagnostic taxonomic validity is claimed here. Cultural interpretation is withheld pending actual source and knowledge-holder review. No public publication was performed by this batch.
