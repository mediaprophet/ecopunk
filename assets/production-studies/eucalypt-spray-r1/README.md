# Eucalypt spray — authored branch study r1

An original illustrative branch-and-leaf asset for Ecopunk. It does not identify a species, locality or specimen and makes no biological-accuracy, cultural-knowledge or human-acceptance claim. Dimensions are authored design choices in metres. No third-party image or audio material was used.

Editable parameters and individual leaf placements are in `authoring/spray.vibe`. A bounded native content helper evaluates that source with Vibe and uses existing QualiaDB sweep, normal, tangent, `.10d`, Q42, HMC and offscreen GPU rendering APIs. It does not replace Poet's workspace and does not establish that the unresolved Poet authoring workflow works.

Intended outputs are `eucalypt-spray.10d`, `knowledge.q42`, `eucalypt-spray.hmc`, an OBJ/MTL interoperability derivative, and real native GPU hero/detail views. Output existence and actual results are recorded separately after generation. The HMC is an asset/resource bundle, not an assertion of native Poet checkpoint admission.

This is a bounded content-production attempt, not a complete species package. Film, open-world-game and cartoon package acceptance, full biological validation, human visual acceptance and all unverified catalogue obligations remain open. The separate complete claim ledger preserves those open obligations.
