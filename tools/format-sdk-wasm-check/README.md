# Actual format SDK WASM compilation probe

This standalone library calls the installed canonical M64 reader, GRM3 producer,
typed caller-buffered frame decoder and opaque retention API. The `portal` Core
profile also compiles the browser-side rendering consumer. No codec, authority,
renderer or graph implementation is copied here.

Use the saved locked offline command/result under Round 3. Compilation for
`wasm32-unknown-unknown` is distinct from executing these APIs in a WASM runtime,
interoperability, scientific validity and native no-JavaScript qualification.
Browser bindings are part of the selected WASM dependency profile. No new asset
or production output is generated by this compilation check.
