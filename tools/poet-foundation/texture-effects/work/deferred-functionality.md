These operations are implemented in the same `apply_filter` body and are not no-ops. Current W2 recipe recommendation exposes Grayscale, Invert and Sepia; the remaining implemented filters below are deferred only from this bounded W2 control scope. Parameter semantics are limited as shown, and require domain-appropriate review before being described more broadly.

| Operation | Existing behavior / limitation | W2 status |
|---|---|---|
| Brightness | Adds `intensity * 100` to each RGB channel; current clamp makes it nonnegative only, with intensity 0–1. Not exposure or symmetric brightness. | Implemented_unexposed |
| Contrast | Multiplies distance from byte value 128 by `1 + intensity`; factor 1–2 only. | Implemented_unexposed |
| EdgeDetect | Simple Sobel-like operation on red channel; copies original alpha; clones full pixel buffer. | Implemented_unexposed |

Do not present these as no-ops or silently relabel their present parameter semantics. If future controls require negative brightness, calibrated exposure, green/blue-aware edge detection, or bounded-memory guarantees, track those as separate contract changes.
