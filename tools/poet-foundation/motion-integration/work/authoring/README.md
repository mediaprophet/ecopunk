The frozen profile supports up to eight distinct material tracks and 64 strictly ordered keys per track, exact authored integer millisecond positions within one day, finite linear RGBA/roughness/metallic factors in [0,1], and outgoing hold/linear/cubic-in-out segments. The total generated cell is capped at 60 KiB, so a combination within individual count limits can still be refused by its actual serialized size. Endpoint sampling holds endpoint values. Alpha sampling preserves the existing material opacity mode; it does not silently enable blend transparency.

`poet_material_motion = {schema:"poet.material-motion/v1",tracks:[{draft:{version:1,material_id:...,keys:[...]},sample_ms:...},...]}` is ordinary editable Vibe source data. The first edit declares it mutable; later edits assign it. The controller must reject a pre-existing immutable binding. `Set` replaces one track and samples it, `Sample` applies an existing track at the explicit time, and `Remove` removes only its recipe while retaining current factors. Unknown schema/fields/modes, invalid time/order/factors, absent or orphaned targets and unsupported colour space fail before source generation. Existing unrelated part/material fields are preserved by the existing authoring builder.
