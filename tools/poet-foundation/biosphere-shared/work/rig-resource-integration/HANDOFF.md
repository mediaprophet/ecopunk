The existing native-project host wraps CheckpointEditorHost in SharedEditorHost and AuthorizedEditorHost. The candidate adds EditorHost::read_selected_resource, forwards through the existing decorators, and wraps the call in cooperation/editor.rs with the existing ReadSource permit. It reuses ResourceInspectionRequest, core::load, CheckpointService path and association checks, release-policy verification, resource summary digest, and current SourceRef checks, plus the existing typed-.10d-style saved/current source-digest coherence. This verifies exact currently selected bytes but is not a licence determination, rig format admission, source edit or user-visible capability.

They are source only, not executed. A real composed native project and eventual rig consumer still need integration coverage.

This is not selected-resource streaming and max_resource_bytes is not an aggregate peak-memory budget.
