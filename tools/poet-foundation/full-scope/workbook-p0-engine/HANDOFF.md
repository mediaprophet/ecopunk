# Bounded native workbook P0 — staged engine and source profile

Status: staged only; no Poet source written, Cargo command, test, user window or production workbook executed. This is a deliberately narrow native first slice, not completion of PA-08, a workbook interchange format or a substitute for imported XLSX/ODS. The [proposed profile](../grid-first-resource-trace/WORKBOOK-PROFILE-DRAFT.md) remains broader and unadopted. Coordinator selected this engineering subset without asserting those open choices were approved as a complete profile.

Requirement and actual owner: native Poet needs an editable workbook operation for the same authoritative human/agent source. GridCraft `crates/engine/src/lib.rs::Session::execute` is the public existing command entry, and `crates/engine/src/cmd/edit.rs::cell_set` is the actual command implementation for protected-cell checks, input parsing, history and recalculation. `workbook_p0.rs` creates a detached actual `gridcraft_engine::Session` from `DocState::new(Workbook::new(),...)` and dispatches every replayed and edited input via `Session::execute("cell.set", {sheet:0,cell,input,array:false})`. GridCraft's real returned `value` supplies display. No formula parser, spreadsheet calculation or formula engine is reimplemented. Poet checkpoint/authority wrappers in the independently staged host own resource selection, permissions, exact package/resource/source digests and atomic commit. UI alone and this module alone are not the vertical workflow.

Exact P0 bytes are UTF-8 JSON with strict `profile = "poet.grid.native/1"`, array of strictly lexically ordered unique canonical `cell` / exact `input` entries; no extra fields or unrecognized versions. The selected HMC resource kind is `poet-workbook-v1` and metadata is refused by the staged host. The blank template is newly created native data; it does not assert authorship, original-file origin, human acceptance or rights. Arbitrary existing JSON, XLSX, ODS, formulas, charts, styles, protected imported sheets and unknown features are not imported or overwritten. They must not be converted silently into this profile. `Sheet1` is the only explicit sheet; the 64x64 A1 address profile allows at most 256 cells; serialized input is at most 128 KiB, each original input at most 256 UTF-8 bytes. Empty explicit input clears that one target. P0 rejects control characters and any `trim_start()` input beginning `=`, `+` or `-`; some ordinary signed numbers are intentionally unavailable. GridCraft scalar parsing can normalize numbers/dates/text displays; the persisted raw input is retained and the displayed GridCraft value is reported separately. This is not a full-fidelity GridCraft Workbook serialization and cannot be used to modify other workbook models.

Admission rejects unknown profile/field, duplicate/noncanonical/unsorted cell addresses and oversized inputs. Inspect and edit check cancellation before and between replayed operations and before encoding; one synchronous GridCraft command itself cannot be interrupted and its worst-case time/memory is not yet measured. Every edit reconstructs a detached candidate session, so engine error does not modify source HMC; existing `save_with_resource_edits` remains responsible for digest-bound atomic publication and unrelated resources. The first P0 source shape can execute at most 257 bounded GridCraft cell commands per edit; no unbounded formula graph is admitted. History is not preserved between detached calls. Fresh-process reopen and work under actual authority remain tests to run, not claims.

Dependency and provenance: `native/Cargo.toml` adds the read-only local `C:/github/poet-gridcraft/crates/engine` path dependency under `native-graphical`; `graphical/mod.rs` registers `workbook_p0`. Ten local GridCraft crates are reachable (engine, core, model, formula, calc, functions, numfmt, xlsx, chart, pdf); their entire crate source trees, workspace Cargo.toml and lockfile, and license/notice files are SHA-256-pinned in [source-pins.json](source-pins.json). Registry dependency source bytes and a final resolved Poet dependency closure are not yet pinned or verified. The dependency is not portable to a machine missing that path; packaging/source-home and redistribution qualification remain open. MIT option selected; exact GridCraft `LICENSE-MIT`, `NOTICE`, and `ATTRIBUTION.md` copies are staged under Poet's `native/third_party/gridcraft/`, and no ArtCraft trademark assets are copied. Transitive third-party license review remains required. Do not edit the GridCraft checkout under current authority.

No locally cached zip 3.x or quick-xml 0.38.x sources or crate archives were found under the standard Cargo registry.
