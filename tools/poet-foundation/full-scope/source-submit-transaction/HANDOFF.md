# Source-submit authority transaction candidate

Staged only; no canonical changes, Cargo or execution. Existing native path: `AuthorizedEditorHost::write` authorizes source operation, `SharedEditorHost` drops its mutex as soon as the raw editor returns, and `CanonicalEditorHost::submit` can commit the actual Studio source, perform runtime effects, and update retained preview before the authority owner post-check returns. The candidate holds the same shared try-lock from inside the admitted callback until owner return, matching selection → authority → shared lock order. `write` covers submit, material, ordinary authoring edits, undo, redo and rebuild; `rig_authoring_edit` now uses the same helper while retaining both authorizations and cancellation check. Nonshared exclusive-host compatibility remains on the existing path; no shared atomicity is claimed for independently constructed wrappers.

On post-dispatch failure it retires derived retained state under the guard or quarantines the shared host if retirement cannot be established. A completed operation without a frame bound to the exact current source, session revision and execution epoch is likewise retired; the successful source snapshot/message remain available if retirement succeeds. An error explicitly says source/effects may have committed, requires reconciliation and never retries or claims rollback. An unsupported retirement capability quarantines; explicitly stateless fixture providers may need to implement safe retirement. `bind_surface_package` changes execution/preview context through a separate read-authorized path and is not included. Guarding source submission does not prove all retained publication paths, GPU behavior or human workflow.

Six source fixture tests check shared lock exclusion during scripted rejection, committed source retention, failure retirement, quarantine, duplicate callback, withheld mismatched session frame, and accepted frame. They are staged, not run; the native owner, GPU and full regression must be checked. See manifest for exact preimages and staged hashes. Treat messages carefully: owner rejection after a callback can follow a durable commit even when returning error.
