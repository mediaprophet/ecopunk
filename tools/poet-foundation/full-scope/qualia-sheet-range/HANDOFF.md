# Existing QualiaDB Sheet operator safety — staged only

Requirement: PA-08 spreadsheet/data work and the user's correction require improving existing QualiaDB Sheet functions in place, not adding a replacement or new JSON workbook. Source trace: `poet_host/invoke/mod.rs` routes exact public IDs `Sheet.stats` and `Sheet.sum_range` to `sheet/range.rs`; existing source test `sum_a1_b2` covers a normal range. The existing operator works on caller-provided Vibe numeric `Value` grids, not a persisted workbook or editable spreadsheet. Source presence/test code is not execution evidence.

Issue: existing A1 column parse uses unchecked `usize` multiplication and addition. Valid but huge range coordinates are iterated cell-by-cell even when almost all positions lie outside the supplied grid. This allows integer overflow or work proportional to nonexistent cells. Candidate retains the exact public IDs, existing ordinary output shape and ragged/reversed/out-of-grid semantics, checks A1 arithmetic, rejects range strings longer than 128 bytes, and intersects requested coordinates with the actual supplied grid before iteration. This changes behavior only for overly long ranges or overflow (explicit error), while huge valid selections return the same result in work bounded by supplied grid size.

Tests: three unit cases in the same owner verify huge row/column bounds, overflow/long input refusal, reversed/ragged/disjoint behavior, with the existing 2x2 case retained. A separate native Poet unit test calls `PoetSnapshot::invoke_id` using `vibe::Value` for both public IDs, checks normal stats, huge selection, ragged/reversed/disjoint results and overflowing column refusal; no JSON, fake UI or authorization is introduced. Native test compiles under the existing guarded Poet workspace. Existing core unit tests require a separately qualified isolated target; no Cargo or test was run by this worker.

Limits: numeric grid coercion and allocations are existing implementation and not newly bounded by this change. Non-finite-value semantics, statistical overflow and user-visible workbook creation/formulas/protection/charts/persistence remain outside this small safety improvement. This does not implement workbook admission/editing, native human workflow, shared human-agent editing or PA-08 completion. Manifest has exact preimage/candidate hashes; coordinator should independently review, preserve existing files, and run the native host test with a nonzero selected count before broader tests/rebuild.
