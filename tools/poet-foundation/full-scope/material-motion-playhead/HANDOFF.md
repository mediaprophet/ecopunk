# Material-motion playhead inspection — staged PA-06 slice

The governing plan requests native composition and motion authoring with editable timing and useful human controls. This narrow change improves Poet’s *existing* material-motion inspector, not an entire composition editor. `authoring/controls.rs` mounts `MaterialMotionControls` and dispatches accepted edits through the existing AuthoringEdit path; `material_motion.rs::MaterialMotionDraft::sample_factors` owns bounded sampling and delegates easing to Vibe animation curves. `native_project_motion_tests.rs` contains signed host/sample/reopen source tests, and `material_motion_tests.rs` exercises existing linear, cubic and hold sampling. Their source presence is not a new test run. The last native regression receipt at `docs/qa/implementation-2026-10-27/full-scope-round1/continuation-surface-binding.md` records 344 passed / 14 ignored for the earlier source snapshot.

The existing panel can add/edit/delete keys and submit an explicit playhead sample, but offered no local interpolated value inspection or adjacent-key playhead movement. The candidate displays the existing domain sampler’s RGBA, roughness and metallic factors for the local key draft at the playhead; it says this is numeric inspection and does not change source or the rendered frame. Pending key fields are explicitly excluded until written into the local key draft. Previous/next key buttons move the local playhead to a strictly adjacent key without wrapping, dropping pending edits or submitting source. A stale/not-fresh inspected view does not display the sample or enable navigation. Invalid time, empty/invalid drafts and boundaries report refusal without mutating the draft or pending fields. Two focused tests cover interpolation and state preservation, and key navigation, boundary and invalid input.

EffectCraft `crates/ui-egui/src/panels/timeline.rs` was consulted as an interaction reference for keyframe/property editing; no source bytes, interpolation, app shell, clock, JavaScript, serializer or GPU owner were copied. Exact inspected source hashes are in the manifest; this is a bounded source trace, not an audit of all other domains. This is not a timeline, continuous playback, rendered frame preview, media export, model/asset completion or human acceptance. The candidate has not been compiled or tested; coordinator must preimage-check, integrate, run focused tests and complete appropriate native checks.
