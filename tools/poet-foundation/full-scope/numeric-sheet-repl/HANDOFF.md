# Staged REPL Sheet routing (uninstalled, untested)

The ordinary REPL previously used Vibe LocalHost, which echoes known Sheet IDs as local records rather than computing. This candidate wraps the existing LocalHost, forwarding non-Sheet behavior as before and declining all Sheet operations when native-graphical is disabled. With that existing feature enabled, it sends four explicitly target-granted operations to existing QualiaDB PoetSnapshot: stats, sum_range, set_cell and the staged bounded formula operation. It refuses receipt-only create/pivot/chart and unknown Sheet methods rather than pretending they succeeded. The wrapper imposes 32x32 shape bounds, per-submission dispatch/work caps and a 256-byte formula/128-byte range; these are abstract limits, not measured memory or cancellation guarantees. Input construction and existing engine overhead precede these checks. No JSON interface or storage is added.

New source-session tests exercise dotted stats and capability.invoke formula, denial of ungranted dynamic targets and receipt-only operations, plus feature-disabled refusal. They are unexecuted: coordinator must run both lightweight and native-graphical tests and rebuild. On a disabled feature the ordinary REPL explicitly declines Sheet functionality; this avoids forcing the large optional native dependency into lightweight builds. LocalHost outside Poet CLI and non-Sheet LocalHost behavior are not changed. Existing CLI grants remain explicit, with target grant enforced for Sheet even for dynamic invocation. Recheck `using`/dotted-source tests against the actual Vibe checker and formula/core staging before install. The source requires all staged QualiaDB changes and Craft dependencies from numeric-sheet-integrated; install only with matching preimages and serial coordinator ownership. This is not a complete workbook.

Follow-up: `poet eval <file> --grant <id>` explicitly opts into the checked SourceSession and the same Sheet host; without grants it preserves the previous eval_cell path, now with zero-grant Sheet refusal instead of an echo. CLI subprocess tests are staged for legacy evaluation, granted native use, target denial and feature-disabled refusal, but not executed.
