# Staged indexed tetrahedral sampled-field extractor

Status: staged, source-reviewed, `rustfmt` parsed, **not compiled or executed**. No canonical sources changed by this worker, no production asset created. Integrator must recheck preimages and independently review all code/tests before serial Cargo.

QualiaDB's existing `isosurface::marching_cubes` returns per-triangle soup and uses a sign-only case table. This optional new Core operation extracts a *different*, explicit piecewise-linear tetrahedral interpolant using a conforming six-tetrahedron cube decomposition. It gives shared vertex indices by exact sorted grid-sample edge identity and returns those edge pairs as local sampling provenance; they are not durable authored identifiers. It checks nonempty output and each indexed edge has exactly two oppositely directed incident faces. It does **not** check a single vertex link, single connected component, self-intersections, genus, biological suitability, UV/normal/tangent mapping, or native Poet/Vibe workflow. No claim of a completed branch junction or high-grade model is justified.

All output/scratch is caller-supplied; there is no heap allocation in the operator. Bounds use checked products and `u32` indices, plus explicit `max_cells` and aggregate hash `max_probes`. The latter includes extraction and edge-incidence hash probes; finite non-hash scans are bounded by checked buffer/cell sizes. Positive finite spacing, finite samples, nonzero distance from isolevel, a strictly exterior boundary, strictly interior interpolation parameter and no rounded endpoint coincidence are required. Exact zero/touching boundary, geometric degeneracy, budget exhaustion and open/directed-duplicate edges refuse. Preflight refusals leave outputs untouched; later errors may write scratch and must not be published. This contract is conservative, and tests do not establish output for arbitrary caller fields.

Existing scalar QualiaDB `sdf_capsule` / `sdf_smooth_union` are used only in a synthetic three-arm fixture; it is a constant-radius, ordered-blend field, not a species, author-controlled taper, or a persisted production recipe. Public-caller fixture checks deterministic sphere, synthetic three-arm indexed edge closure and connectivity, zero/boundary refusal, no-op buffer safety, empty field, numeric collapse, hash probe exhaustion, nonfinite inputs and unchanged preflight buffers. The synthetic Y asserts output near each supplied endpoint. The Core-only staged tests also cover strict rounded endpoint behavior in both orientations and edge-validator negative cases. No Core dependency-crate unit test is automatically run by Poet. All tests remain unrun.
