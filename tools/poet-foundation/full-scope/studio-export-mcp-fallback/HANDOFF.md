# Qualia MCP Studio.export error propagation — staged

Trace: `qualia-mcp/src/dispatch.rs` routes `poet_artifact_lifecycle` and `poet_studio_domain` to `tools/poet.rs`. Both use `PoetSnapshot::live().invoke_id`, which dispatches `Studio.export` through Qualia Core. Before this candidate, `poet_artifact_lifecycle` silently replaced any error in the unqualified `export` action with a fabricated `status: exported` response. `poet_studio_domain` fell back to the same lifecycle handler on Studio errors, which also mishandled capability-only requests. This is the separate Qualia MCP surface; current evidence does not show Poet native's own MCP uses this tool.

Candidate: on a real `Studio.export` invocation error, both tools return `McpSystemError::ExecutionFailed` carrying the diagnostic. The fabricated export-success branch is removed. Documented MCP `artifact_id`/`target_format` aliases are normalized to the Core `id`/`format` fields, conflicting or non-string aliases fail closed, and omitted format still defaults to Q42. The domain tool skips its unrelated post-export `Studio.edit` attempt and fabricated target/clock/quin metadata. Existing Core rejects that edit attempt because it lacks `id`; no actual source mutation was demonstrated. Successful real exports and all other lifecycle fallback branches are unchanged. This is deliberately narrow: fabricated success/fallbacks for other lifecycle actions and unrelated studio-domain capability receipts remain open. It relies on the separate Core office/CSV fail-closed fix; by itself it propagates whatever Core reports and does not implement formats or authorization.

Four separately located focused tests cover real Core-created artifacts through both MCP tools: office export refusal, missing artifact, unsafe CSV refusal, successful simple CSV, legacy aliases, conflicts and invalid values, omitted-format default, suppression of fabricated metadata and source preservation. The added support and test files keep the existing tool file below 500 lines. These tests are staged, not compiled/executed. Exact preimage/candidate hashes and absent-new-file checks are in [manifest.json](manifest.json); a coordinator must preserve any intervening source work and install the new file explicitly. Suggested guarded check: `cargo test --locked --offline -p qualia-mcp --lib mcp_studio_export -- --test-threads=1` with the established target, resource guard and native access if required. Confirm nonzero tests and separately perform requested Poet regression/build; no cross-repo completion is established until actual checks run.
