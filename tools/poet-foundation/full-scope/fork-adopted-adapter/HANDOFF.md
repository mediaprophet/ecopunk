# Staged single-junction source and generator

These files are isolated candidates under Ecopunk; they are not registered, installed, compiled or executed. No Poet tests, build, or asset production occurred. The source codec uses a separate opt-in Vibe record containing an existing v1 graph and explicit grid/field/area settings. It preserves the graph value on a position edit and refuses v2, because the current v2 evaluator is chain-only. The source bytes and the full incoming Vibe value must be bounded by the host before the codec is called.

The adopted adapter checks one rooted four-organ graph and maps its three adjacent edges and pipe radii into QualiaDB field segments. The generator samples that field, calls the existing indexed tetra extractor, and applies the actual-probe-budgeted topology qualifier. It returns scratch buffers only. A topology receipt is not evidence of surface self-intersection freedom, branch correspondence, normal/UV continuity, biological validity or human acceptance. The sample edge pairs identify grid samples, not biological organs.

Each axis is screened for distinct consecutive f64 grid positions under an explicit host-selected work cap. Element payload is preflighted with checked arithmetic; allocation uses try_reserve_exact and checks actual Vec capacity before initialization. Because capacity becomes known only after allocation, excess capacity may exist transiently before refusal. The accepted-capacity cap excludes allocator metadata, source/session values, stack, GPU, process memory and independently retained previews. A caller must reserve all relevant stages and lifetimes through a reviewed shared transaction ledger. The candidate does not itself constitute aggregate resource enforcement.

A future integration must place junction_source.rs beside Poet botanical recipe.rs and explicitly re-export JunctionSource; the two other modules need graphical module declarations. Before any route is exposed, review and implement source-string serialization, transactional work and source-memory accounting across edit/submit/replay, host authority and stale-source checks, prior projection matching, authored UV/normal/skin/unknown-stream preservation or refusal, and safe scratch publication. Re-pin affected files and run appropriate source/host/reopen/GPU tests only as instructed by the user. The staged operation ledger was independently reviewed and currently charges no real operations; it is not a production admission gate.

An independent source review identified grid rounding collapse and underestimated Vec capacity; both were addressed in the staged generator. The reviewer confirmed the fixes at source level, with the transient-allocation limitation above. No execution result is implied.
