# Hard-cap sweep normal derivative — staged, unexecuted

`hard_cap_sweep.rs` proposes a separate optional public QualiaDB operator. It calls the existing Core `extrude_profile_along_path` and `vertex_normals`; it does not replace either. The caller provides frame, vertex, triangle, normal and source-index-mapping buffers. Checked preflight establishes bounds before writing; failures after starting the sweep can leave scratch outputs modified and must not publish them. No heap allocation, imported framework or JSON is introduced in the operator. A caller must impose an appropriate station/work limit and cancellation policy; the generic API has no internal cancellation.

It duplicates both cap rims, retaining equal positions but separate indices so the cap normals do not blend into wall normals. Original centroid and wall vertices map to themselves; duplicate rim vertices map to their original sweep indices for explicit attribute migration. These mappings are per-generated-sweep indices, not durable identifiers. The result is a **render derivative**, not an index-watertight topological master. Do not replace an editable source or HMC master with it or overwrite authored normal/UV/skin streams. This operation adds no UV or tangent stream, makes no guarantee about texture stretch, and does not join branches at forks.

The first candidate's triangle-area wall normals had a demonstrated diagonal bias. The reviewed staged revision instead sums each quad's two oriented triangle-area vectors and contributes that one value to each quad corner. This avoids that bias for a planar constant-radius sweep; the stage includes straight-cylinder radial and matching-station assertions, hard-cap separation, tapered/gentle bend orientation and finite-unit assertions, size/finite/clockwise/negative-scale refusal and degenerate/reversal tests. Normal quality for arbitrary twisted or nonplanar quads, tight bends, self-intersection and human/biological visual acceptance remains unqualified. Section input is restricted to 3–64 strictly convex simple CCW points; the conservative intersection check may reject valid collinear line extensions.

Independent review checked the quad method, cap split, mapping and preflight by source inspection; it found no further definite blocker but did not run tests. `rustfmt --edition 2021 --config skip_children=true --emit stdout` parsed the Core operator and Poet caller fixture. No Cargo, compiler, GPU, UI or production asset was run. Product/host/VibeScript functionality does not yet call this operator. The staged Poet test calls the public typed Core function directly and is not a native workflow or rendered result.
