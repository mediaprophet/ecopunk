# Native Sheet.stats positional wrapper correction

Vibe `payload_from_args` wraps one dotted positional list into exactly `{t, value}`. The installed GeometryHost rejects that as a record without `grid`; the REPL already supports the wrapper. The staged host unwraps only the exact two-field same-numeric-list wrapper for Sheet.stats. Both lists are shape-checked to the existing 4,096-row / 65,536-work caps before equality; integer variants and float bits are compared exactly, including NaN payloads and signed zero. Existing target grants, normal non-wrapper record/grid handling and downstream Sheet owner remain unchanged. Wrapper dispatch is consumed before either scan; each validated element and the bounded comparison debit the existing work counter before inspection, including when normalization fails. A successful wrapper then pays the normal downstream grid work without consuming a second dispatch.

`sheet_range_session_tests.rs` stages source calls for flat, ragged and record arguments and host tests for non-finite/signed-zero, oversize, nested and mismatched wrappers, exact work-budget exhaustion, and unchanged non-wrapper charge. Existing capability.invoke and grant tests remain. No native tests or build were run; rustfmt checked syntax only. Confirm manifest preimages after the active build, integrate through coordinator, and run the named focused native tests; do not alter active builds. A shared common helper with the REPL remains a future deduplication opportunity, not required to apply this narrow fix.
