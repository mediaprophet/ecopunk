## Exact missing contract before safe workbook admission

Select and document an owner-approved, versioned editable workbook resource profile and identify its implementation owner. The contract must specify (1) exact kind/schema and version compatibility, (2) original file/source, rights and derivation retention, (3) unknown field/feature behavior and loss reporting, (4) hard file/decompression, sheet/cell/string/formula/recalc/history/cancellation budgets that include already existing importer bounds, (5) session identity, revision, undo/recalc and mutation ownership, and (6) authorization and source/package/resource digest/revision binding. Native rights and capability checks must be performed by the existing host; filename or metadata alone cannot authorize a workbook. Preserve arbitrary imported XLSX/ODS source byte-exactly until explicit supported output/review permits a derivative; do not automatically rewrite it from an incomplete model.

The immediate engineering seam is the selected HMC checkpoint owner, not a replacement engine: a profile-specific decoder should be called only after authenticated source and exact package/resource selection with pinned revision, then reuse GridCraft `Session::execute("cell.set", ...)` at one authoritative session and the existing checkpoint resource edit owner for safe commit. Resolve the engine's actual dependency/provenance path and unknown feature policy before implementing an adapter. A one-off wrapper with a newly invented resource kind, unrestricted JSON deserialize, fake receipt or UI-only local state would be disconnected from those requirements.

Minimum acceptance cases: exact admitted profile success and formula/dependent recalc; protected sheet refusal; unknown schema/features and unsupported import reported without destructive rewrite; excessive input/decompression/formula/work budget and cancellation refusal; stale source/session/package/resource digest and denied authority refusal; exact preservation of unrelated HMC resources and original workbook source; concurrent conflict; undo and fresh-process reopen; human and separately authorized agent using the same authoritative command. Capture executable result and pin concrete source/dependencies/output; source inspection alone does not pass any case.
