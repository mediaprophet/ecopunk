# Numeric grid native UI staged handoff

The native controls inspect a bounded existing poet_sheet binding and change one finite numeric cell via the existing typed source session and the Sheet.set_cell operation. The UI explains how to submit an explicit starting source binding and does not replace existing content automatically. Authenticated clients dispatch NumericSheetIntent through the existing NativeIntentBus actor inspection, source/session validation, provenance and receipt path; only the new typed in-process payload is used, with no new JSON interface. Unauthenticated local diagnostics use the established direct worker route. The UI protects pending drafts, withholds stale inspection replies, and binds edits to the inspected execution epoch. Contributor authority remains with the host wrappers. Remote/MCP exposure is not supplied.

Manifest records target preimages and candidates. jobs_tests stages a synthetic post-read successor and stale-origin refusal; workspace_tests stages signed software-agent actor receipt, source-staleness, revoked-session and observer read-admission/execute-denial cases. The host worker separately staged signed project, HMC reopen and source-replay tests. Role-specific behavior is staged but unexecuted; independent ReadSource denial is represented by session revocation rather than an admitted role lacking read permission. Built native GUI interaction and remote agent workflow remain unproven. These tests have not been compiled or run; rustfmt parsed the new component and intent files only.
