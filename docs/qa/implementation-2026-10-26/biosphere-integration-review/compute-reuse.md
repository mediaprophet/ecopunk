## Required admission, state and semantic invariants

- **Input:** borrowed preflight before allocation/dispatch; exact record/row schemas, finite bounded values, checked integer conversion/products, units/frame/handedness, positive physical values, supported enum/profile and pinned schema/operator versions. Parent graph must be rooted, acyclic and parent-before-child where the solver requires it. Explicitly reject bad/self/out-of-range parents rather than relying on kernel omission.
- **Work:** cumulative input/output/scratch/GPU/work limits over all invocations, including node×attractor×iteration, mesh projection V×F×passes, particle×constraint×iteration, body-pair×substep, source/rule/result and trace costs. Account for actual implementation capacity formulas. These host working limits are not master-quality ceilings; high-detail cold jobs need explicit caller-backed admission.
- **Cancellation:** use existing caller cancellation/workspace infrastructure where wired. Kernels lacking safe checkpoints require bounded short atomic calls or an owner-level cancellable variant before long jobs. Cancelled/superseded/failed results cannot publish, mutate the accepted session, overwrite private edits or retain an unreported partial topology. Bound cancellation latency and demonstrate the bound using the chosen workload; do not invent a number.
- **Topology:** preserve connectivity, orientation, material/UV seams, organ membership, rig/skin/morph/collider correspondence and explicit old→new lineage. Welding by position alone can merge distinct biological parts. Remeshing/isosurface conversion must report error/coverage and refuse unsupported preservation; absence of lineage prevents adoption as an edited rigged master.
- **State/meaning:** one canonical source/session plus versioned simulation checkpoint; preserve seed, tick/dt, environment, parameters, state and event order through undo/rebuild/HMC replay. Taxon, organism instance, organ, representation and package release remain distinct; hashes/array positions are not universal identifiers or authority. Every model law/parameter and inferred fact carries source/units/assumption/uncertainty. Animation, simulation prediction and observation remain distinguishable.
