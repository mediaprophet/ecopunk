## Changes required in the implementation allocation

1. **Preserve the existing domain-to-state seam.** The next tree slice should explicitly bind sim metamer/leaf state to existing botanical quins and the correct selected biological network. The next wallaby slice should bind rig/contact/events to retained component identifiers and existing hydrological/environmental state where used. Add unit/quantization, context, frame, source and instance/organ correspondence acceptance; do not design new parallel state or solver frameworks.
2. **Qualify shared orchestration before calling it an enforcement gate.** Blackboard/DAG path already exists, but a hard-constraint label alone cannot block adoption. Bounded owner work must prove validation before accepted-state promotion, checked propagation/write failures, deterministic clock/parity semantics, finite input/work quotas and cancellation/rollback without false success. Keep UI/session integration in Poet; do not copy domain solvers there.
3. **Treat instruments as packaging/attestation foundations with demo execution.** Reuse package, manifest, resolve, VC/status and receipt owners. Allocate actual declared dependency closure and selected typed instrument execution separately, using exact adopted/reviewed policy inputs only when that later scope is ready. Actual content/right/contribution records start with authoring; payment rails remain IP-08 support work and are not a first-output prerequisite.
4. **Require output proof at each used seam.** Retain exact source/release/operator/parameter IDs, units and output hashes. Exercise real owner APIs with known positive/negative fixtures: wrong world/subject/opcode, stale source, unknown required fields, quantization boundaries, bad registrations, overflow/oversized work, duplicate/reordered state, missing/revoked dependencies, rejected hard constraints and cancelled jobs. Fresh-process HMC reopen must recover source, state, graph mappings, rights/review lineage and usable native contributor/reviewer output. A source test, generated receipt, signature or catalogue label cannot replace actual native interaction/domain review.
