## Saved implementation

Five canonical Poet targets were saved and their final bytes checked:

- `C:/github/poet/native/src/graphical/geometry_host.rs`: explicitly granted
  `ComputationalGeometry.turtle_3d` dispatch, with cumulative work/dispatch charge.
- `C:/github/poet/native/src/graphical/turtle_host.rs`: borrowed-input admission
  before Core allocations; exact command shapes, finite numbers, positive
  dimensions, bounded stack/polygon/ring/capacity and checked scratch/work costs.
- `C:/github/poet/native/src/graphical/turtle_host_tests.rs`: seven new actual
  kernel/preview admission and refusal cases.
- `C:/github/poet/native/src/graphical/biological_reference_tests.rs`: explicit
  ignored native GPU diagnostic for three Vibe sources and canonical editor.
- `C:/github/poet/native/src/graphical/mod.rs`: test-module registration.

Geometry is generated by the existing **QualiaDB** host and computational
geometry kernel. No tree generator, mesh implementation or replacement engine
was copied into Poet. QualiaDB and Etalon implementations were not modified.
The wrapper intentionally narrows the Core command profile; its bounds are host
working limits, not species sizes or an accepted master-quality ceiling.

## Review corrections and failed attempts

Keep the failed receipts: [initial](initial/biology-host-result.json),
[registration repair](corrected/biology-host-result.json), and
[encoding repair](utf8-corrected/biology-host-result.json). The first exposed
literal newline escapes in the new module registration. Supervisor repairs then
introduced a non-UTF-8 title byte and doubled carriage returns respectively.
These were tooling/registration errors, not engine-capability failures; the
final checked source preserves UTF-8 and valid line endings. No failed attempt
is counted as a pass. The diagnostic's vector/title types, misleading filename,
source/frame checks and pixel-variation claim were also corrected during review.

The cost-routed workers delivered the host, botanical source fixtures and render
harness; the supervisor reviewed, repaired, installed, ran and retained the
results. No worker completion message was treated as executed qualification.
