## License, notices, assets, and external material

The repository claims dual MIT/Apache licensing (`Cargo.toml:6-11`, `README.md:367-375`, `LICENSE-MIT`, `LICENSE-APACHE`). `NOTICE` identifies the copyright and dual-license choice, enumerates third-party material, and points to the asset-level `ATTRIBUTION.md`; that index says each listed repository asset has an `.attribution` sidecar. The visible `rg --files` listing contains **57** such sidecars. The current inventory did not audit every asset-to-sidecar pair, every Cargo.lock dependency license, or the complete third-party license closure. `NOTICE` also identifies bundled dependency fonts and the optional `craft-pdf` reader's MIT/Apache terms. Preserve the full root license texts, `NOTICE`, `ATTRIBUTION.md`, applicable sidecars, and each imported dependency's own license/NOTICE; no global relicensing is inferred.

The eight files under `docs/brand/` are ArtCraft wordmarks/marks. `NOTICE`, `ATTRIBUTION.md`, `docs/brand/LICENSE-brand.txt:1-42` state they are trademarks outside the project license, limited to EffectCraft's own identity, and must be removed from forks/modified versions. **Do not import those marks into Poet or any Ecopunk derivative.** The separate `assets/app-icon/LICENSE.txt` addresses the EffectCraft app icon and its derived icons; this does not make the ArtCraft brand marks portable. App identity, website screenshots, demo material, model weights, and provider/account state are not reusable engine dependencies. Model weights are described as optional downloads, not bundled assets (`ATTRIBUTION.md:100-127`).
