## Small wording safeguard

Line 71 says “ten species/all domains/quantum precomputation are not new serial prerequisites.” Read alone, that could be misconstrued as dropping the wider requirements. The adjacent “These extend existing … cases” and “not … silent catalogue scope reduction” at lines 49–50, the broader obligations at lines 22–47, and the R-job table at lines 117–125 resolve that ambiguity in context. When this wording is copied into an assignment, retain the surrounding statement that broader obligations remain visible and are handled through later/case-specific existing work; do not quote only the exclusion.

Similarly, “14 is UV” at line 57 is terse shorthand, while the technical report gives the current enum name `TextureCoordinates`. The row already states this is a correction against reusing tag 14 as `VOX0`; spelling out “UV/texture coordinates” in a future copy would make the mapping clearer without changing the ABI.

These are clarity safeguards, not blockers or reasons to change the original source document.
