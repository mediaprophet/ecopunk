# Geography Libraries (`EarthCraft`, `Nerthus` & `RustGIS`) — Source Review and Poet/Ecopunk Adaptation Package

**Date:** 2026-10-28 (v1.1 — updated with `RustGIS-main`) · **Current scope:** read-only source research, requirements reconciliation, documentation and prepared handoffs. No engine/source refactoring, Cargo build, test execution, export, GUI launch, network/provider invocation or asset production occurred. No native product, place master or model completion is claimed.

The additional source root `C:/github/geography-libraries` contains three independent permissive-licensed Rust workspaces:
1. **`EarthCraft-main` (`v0.2.0`, MIT)**: A 4-crate pure-Rust 3D globe explorer (`earthcraft-core`, `earthcraft-data`, `earthcraft-render`, `apps/earthcraft`) implementing WGS84 (G2296) / spherical geodesy, Karney ellipsoidal geodesics (`geographiclib-rs`), `DD`/`DMS`/`DDM`/`UTM`/`UPS`/`MGRS` coordinate parsing/formatting, IAU 2006/2000A celestial/solar ephemeris (`sofars`), CelesTrak Keplerian orbit propagation, ray-anchored globe camera + smooth geodesic `FlyAnim`, hardened KML/KMZ ingestion (`guard.rs`), Hilbert-packed R-tree spatial/label indexing (`geo-index`, `rstar`), two-tier `moka` + SQLite `.mbtiles` caching, and `wide::f64x4` SIMD ray-casting with hybrid GPU (`wgpu`) overview compute + CPU limb/seam precision repair.
2. **`nerthus-main` (`v2.3.1`, MIT)**: A 14-crate clean-room Rust reimplementation of QuadSpinner Gaea 2.3.1.0 (`nerthus-core`, `nerthus-engine`, `nerthus-noise`, `nerthus-image`, `nerthus-erosion`, `nerthus-compute`, `nerthus-nodes`, `nerthus-assimp`, `nerthus-io`, `nerthus-hevc`, `nerthus-export`, `nerthus-render`, `nerthus-app`, `nerthus-cli`) implementing 182 procedural terrain node builders, 19 modifiers, 5 native C++ erosion/hydrology engine ports (`ce` classic droplet/thermal, `cs` orographic snow, `cw` shallow-water lake/sea + `SpanFill`, `hydro` priority-flood drainage & river carving, `ts` thermal shaper), deterministic 8.24 fixed-point multi-scale hydraulic erosion (`ParallelErosion_Erode` in CPU + `parallel-erosion.wgsl`), 12 WGSL compute shaders, Bruneton precomputed atmospheric scattering (`sky.wgsl`), 323 Copernicus Sentinel-2 colour LUTs, QEM mesh decimation, 19 raster/point-cloud + 8 mesh export formats, and 38+ MCP authoring/geomorphology-report tools.
3. **`RustGIS-main` (`v0.4.0`, Apache-2.0)**: A 16-member pure-Rust desktop/web/CLI/Python GIS suite (`rustgis-geom`, `rustgis-data`, `rustgis-map`, `rustgis-analysis`, `rustgis-geolibre`, `rustgis-render`, `rustgis-tiles`, `rustgis-engine`, `rustgis-plugins`, `rustgis-assistant`, `rustgis-ui-egui`, `rustgis`, `rustgis-cli`, `rustgis-python`, `rustgis-web`, `xtask`) with `unsafe_code = "forbid"` and zero mandatory C/C++ GDAL/GEOS dependencies. It provides 16 vector/point-cloud readers/writers (`GeoPackage`, `GeoParquet`, `FlatGeobuf`, `Shapefile`, pure-Rust `Esri FileGDB` v10+, `LAS`/`LAZ`/`COPC` LiDAR, `OSM PBF`, `DXF`), full OGC web clients (`WFS 1.1/2.0`, `OGC API Features`, `WMS`, `WMTS`, `WCS`, `CSW`, `SOS 2.0`, `SensorThings v1.1`, `STAC API`, `ArcGIS REST`), HTTP-Range `COG` & `Zarr v2/v3`/`NetCDF-3`/`GRIB2` multidimensional `DataCube` readers, `proj4rs` + WKT1/WKT2/ESRI CRS reprojection, 21 built-in geoprocessing tools (`buffer`, `clip`, `intersect`, `dissolve`, `spatialJoin`, `zonalStats`, Ordinary `kriging`, `viewshed`, Dijkstra `RoadGraph`, 6 `topology` rules/auto-fixes, `a5` pentagonal DGGS) + 1,000+ GeoLibre/Whitebox tools, `MVT`/`PMTiles` vector tiles, camera-relative `f64`$\rightarrow$`f32` `lyon` GPU tessellation, topological shared-vertex editing (`edit.moveSharedVertex`), `PutAside` CoW delta undo/redo, and cartographic `PageLayout`/`MapSeries` PDF/SVG/glTF export.

Start with the [Geography Libraries Adaptation Guide](../../../planning/tech/geography-libraries-adaptation-guide.md). Reuse is **requirements-first**: source libraries accelerate existing QualiaDB (`qualia-geospatial`, `qualia-core-db`, `qualia-sim`), Etalon, Webizen and Poet contracts; their standalone `eframe`/`egui` or `bevy`/`bevy_egui` shells, private `wgpu` devices, OS driver/registry shims, and unauthenticated local servers do not replace the native ecosystem architecture.

## 2. Three-Way Synergy Across `EarthCraft`, `Nerthus` & `RustGIS`

1. **`EarthCraft` (Planetary & Geodetic Frame)**:
   - Supplies WGS84 ellipsoidal math, `DD`/`DMS`/`DDM`/`UTM`/`UPS`/`MGRS` coordinate conversion, geodesic distance/bearing measurement, IAU 2006/2000A celestial/solar positioning (`CelestialFrame`), KML/KMZ security guards (`guard.rs`), and smooth geodesic camera flight (`FlyAnim`).
2. **`RustGIS` (Real-World Geospatial Ingestion, Geoprocessing, Topological Editing & Cartography)**:
   - Supplies the complete **5-layer Kosciuszko / Snowy Mountains real-data ingestion pipeline** (`map-layers.md` Layers 0–4): `LAS`/`LAZ`/`COPC` LiDAR (`lidar.rs` $\rightarrow$ `.m64` `E64PointRecord`), `WCS` & HTTP-Range `COG` DEMs (`cog.rs`), `WFS 2.0`/`OGC API Features`/`GeoPackage`/`GeoParquet`/`FlatGeobuf`/`FileGDB` geology & hydrography vectors (`ogc.rs`, `io.rs` $\rightarrow$ `.q42` `NQuin` `geo:Feature`), `SOS 2.0`/`SensorThings` observations ($\rightarrow$ `sosa:Observation` NQuins), and `STAC`/`Zarr v2/v3`/`NetCDF-3`/`GRIB2` climate/remote-sensing cubes (`zarr.rs` $\rightarrow$ `.10d` `FIEL`).
   - Supplies **spatial analysis & topological authoring**: 21 built-in geoprocessing tools (`buffer`, `clip`, `intersect`, `dissolve`, `spatialJoin`, `zonalStats`), Ordinary `kriging` (`kriging.rs`), `viewshed`, Dijkstra `RoadGraph` (`network.rs`), 6 automated `topology.rs` rules/fixes, `vertexedit.rs` shared-vertex topological polygon editing (`edit.moveSharedVertex`), camera-relative `f64`$\rightarrow$`f32` `lyon` GPU tessellation (`gpu_scene.rs`), `MVT`/`PMTiles` vector tiles, and `PageLayout`/`MapSeries` cartographic publishing.
3. **`Nerthus` (Procedural Landform Synthesis, Physical Erosion, Hydrology & Stratigraphy)**:
   - Takes real or authored base DEMs and geological unit masks and refines them with 182 node builders, priority-flood drainage (`HydroFix`), primary/secondary/tertiary river carving (`Rivers`), 8.24 fixed-point deterministic hydraulic erosion (`ParallelErosion_Erode` in CPU + `parallel-erosion.wgsl`), shallow-water lake/sea `SpanFill` (`CWEngine`), orographic snow (`CSEngine`), thermal talus relaxation (`TSEngine`), geological stratification (`Stratify`, `Strata`, `Outcrops`, `Fault`), and 323 Sentinel-2 colour LUTs (`CLUTer`) to populate `.m64` `M64StrataColumnRecord` 6-layer columns and `.10d` `FIEL`/`MESH` masters.
