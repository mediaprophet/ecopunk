## 1. Executive Summary for Poet & QualiaDB Integration

`RustGIS-main` (`v0.4.0`, Rust 2024 edition, `Apache-2.0`, `unsafe_code = "forbid"`, workspace-wide `#![deny(clippy::unwrap_used, clippy::expect_used, clippy::panic)]`) is a full-featured desktop/web/CLI/Python GIS suite written in pure Rust without any mandatory C/C++ GDAL or GEOS runtime dependency.

Its 10 headless domain crates (`rustgis-geom`, `rustgis-data`, `rustgis-map`, `rustgis-analysis`, `rustgis-geolibre`, `rustgis-render`, `rustgis-tiles`, `rustgis-engine`, `rustgis-plugins`, `rustgis-assistant`) have **zero UI dependencies** and fill the exact **GIS vector/raster/point-cloud/OGC ingestion, spatial analysis, cartographic layout, and 2.5D/3D vector extrusion gaps** between `EarthCraft` (planetary globe) and `Nerthus` (node-based terrain/erosion):
- **16 Vector/Tabular & LiDAR Providers (`rustgis-data`)**: Pure-Rust readers/writers for `GeoJSON`, `Shapefile`, `GeoPackage` (`.gpkg`), `GeoParquet` (`.parquet`), `FlatGeobuf` (`.fgb`), `Esri FileGDB` (`.gdb` v10+ binary tables without GDAL), `LAS`/`LAZ`/`COPC` LiDAR point clouds (`laz`), `OSM PBF`, `AutoCAD DXF`, `KML`/`KMZ`, `GPX`, `TopoJSON`, `GeoRSS`, `WKT`/`EWKT`, `CSV`/`TSV`, and `Excel`/`ODS` (`calamine`), plus live `PostGIS`, `MySQL`, and `SQL Server` connectors.
- **Full OGC, STAC & Cloud Raster Suite (`rustgis-data`)**: Native clients for `WFS 1.1/2.0`, `OGC API - Features`, `WMS 1.1.1/1.3.0`, `WMTS 1.0.0`, `WCS 1.0/2.0.1`, `CSW 2.0.2`, `SOS 2.0`, `SensorThings v1.1`, `STAC API`, `Esri ArcGIS FeatureServer/MapServer REST`, and `OSM Overpass QL`, plus `GeoTIFF`, HTTP-Range `COG` (`cog.rs`), `Zarr v2/v3`, `NetCDF-3`, `GRIB2 WMO FM 92`, `SAFE Sentinel-1/2`, `SRTM HGT`, and `ENVI BIL/BIP/BSQ`.
- **CRS Reprojection & Geodesic Area/Length (`rustgis-geom`, `rustgis-map`, `rustgis-data/src/raster/crs.rs`)**: `proj4rs` + `crs-definitions` + pure-Rust WKT1/WKT2 (`wkt.rs`), ESRI `102xxx`/`103xxx` (`esri.rs`), 18 map projection presets (`EqualEarth`, `Robinson`, `GoodeHomolosine`, `AlbersEqualArea`, `LambertConformalConic`, etc.), Karney WGS84 geodesic polygon area (`PolygonArea`) across 12 solar-system `BODIES`, and ear-clip polygon triangulation with hole bridging (`triangulate.rs`).
- **21 Built-In Geoprocessing Tools + 1,000+ GeoLibre/Whitebox Tools (`rustgis-analysis`, `rustgis-geolibre`)**: Vector overlay (`buffer`, `clip`, `erase`, `intersect`, `identity`, `union`, `dissolve`, `spatialJoin`), `zonalStats`, `kriging` (Ordinary Kriging with Spherical/Exponential/Gaussian semivariograms), `idwInterpolation`, `viewshed`, `line_of_sight`, `contours`, Dijkstra `RoadGraph` routing/isochrones (`network.rs`), 6 automated `topology.rs` rules/fixes, `a5` pentagonal equal-area DGGS (`dggs.rs`), 2-layer `Mlp` neural raster classifier (`neural.rs`), and `rustgis-geolibre`'s bridge to 1,000+ Whitebox/GeoLibre hydrological/LiDAR/SAR tools.
- **Vector Tile (`MVT` / `PMTiles`), Camera-Relative `lyon` GPU Tessellation & Cartographic Print Layouts (`rustgis-tiles`, `rustgis-render`, `rustgis-map`)**: Zero-protoc Mapbox Vector Tile v2.1 decoder (`mvt.rs`), PMTiles v3 Hilbert-curve reader (`pmtiles.rs`), MapLibre GL Style v8 evaluator (`style.rs`), camera-relative `f64`$\rightarrow$`f32` `lyon` tessellation (`gpu_scene.rs`, `F32_REACH_PX = 2^23`), `cosmic-text` complex-script/RTL curved label placement, `PageLayout` + data-driven `MapSeries` PDF/SVG export, QGIS `.qgs`/`.qgz`/`.qml` import/export, and glTF 2.0 / OBJ 3D scene export (`export_scene_gltf`).
- **Command-Centric `Session` + `PutAside` Delta Undo + ModelBuilder DAG (`rustgis-engine`)**: 51 command modules where UI, CLI, Python, ModelBuilder DAG (`model.rs`), and MCP (`mcp.rs`) execute identical `CommandSpec` handlers with copy-on-write `PutAside` undo/redo (`MapMeta`, `LayersMeta`, `OneLayer`) that avoids cloning multi-megabyte `Arc<Dataset>` / `Arc<Raster>` buffers.
