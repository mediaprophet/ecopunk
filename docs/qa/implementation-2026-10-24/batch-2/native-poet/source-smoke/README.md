This harness imports actual source paths; it contains no candidate module, duplicate document store, fake Host or private renderer. Its observer records the actual public kernel result and delegates rendering to the applied provider.

The complete native feature/dependency profile matches the actual Poet package. They are not organism/assembly deliverables or high-grade accepted masters.
