# VibeScript Sheet exposure: source audit, 2026-10-28

The direction is one authoritative set of domain operations available to VibeScript across capable hosts, subject to the host's actual grants, role and resource checks. A catalog name alone does not establish an implementation or a working route. This audit describes installed source, not executed verification.

- QualiaDB's existing Sheet dispatcher has real bounded `Sheet.stats` and `Sheet.sum_range` in `C:/github/qualiaDB/crates/qualia-core-db/src/poet_host/invoke/sheet/range.rs`, and newly integrated `Sheet.set_cell` and `Sheet.eval_formula` in the same `sheet` module. Formula evaluation uses typed GridCraft parser/calculator components. These operate on supplied numeric grids, not persistent workbooks.
- `Sheet.create`, `Sheet.pivot_analyze`, and `Sheet.chart_spec` in `C:/github/qualiaDB/crates/qualia-core-db/src/poet_host/invoke/studio_domains.rs` return receipts. They do not implement creation, pivots or charts, and the integrated native and REPL routes deny them.
- Poet's native project host routes the four bounded operations via `C:/github/poet/native/src/graphical/geometry_host.rs`, with grants configured in `native_entry/create.rs`; its numeric controls edit an existing `poet_sheet` source binding. The separate native-graphical REPL/eval host requires explicit target grants; lightweight configurations refuse Sheet operations. The generic Vibe `LocalHost` still echoes known IDs in `C:/github/qualiaDB/crates/vibe/src/catalog/local.rs`, so catalog registration and that host's response do not prove domain execution.
- The installed native host lacks normalization of Vibe's dotted positional `Sheet.stats([1,2])` argument wrapper, although the REPL handles it. A metered correction and tests are staged at `C:/github/ecopunk/tools/poet-foundation/full-scope/numeric-sheet-native-positional`; they are not installed or tested as of this entry.
- `set_cell` is limited to a rectangular nonempty numeric grid of at most 32 by 32. Formula evaluation is bounded to numeric inputs, 256-byte expressions, 64 AST nodes, depth 16, scalar arithmetic and SUM/AVERAGE/MIN/MAX/COUNT; it does not retain cell expressions, maintain a dependency graph, or create a workbook. The native formula host charges 131,072 work units per call against a default 2,000,000-unit replay budget. Native range functions and REPL have different input bounds. Existing raw range admission can inspect row headers before final budget checks.

Open work includes general host routing and consistent call forms, real creation/editing/persistence, text and styled cells, formulas and dependency recalculation, multi-sheet operation, import/export, pivot/chart computation and presentation, actual native contributor/reviewer workflows, and verified WASM support. Trace and extend existing QualiaDB, Poet and appropriate Craft implementations before assigning a replacement; preserve source notices. The active native test and eventual rebuild must be recorded separately when complete.
