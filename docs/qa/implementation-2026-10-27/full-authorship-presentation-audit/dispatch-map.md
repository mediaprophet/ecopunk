# Restartable work allocation

This is an allocation map for the existing [implementation plan](../../../planning/implementation-plan.md) and [job register](../../../planning/biosphere-work-packets.json), not a competing phase order or evidence that any job ran. The current user authorized this audit as an alternative to implementation; completing the audit alone does not dispatch these jobs. A later user instruction to resume implementation is sufficient direction, subject to the existing sandbox, ownership and review rules.

## Coordination contract

Each row can be assigned to one worker with the indicated exclusive **staging** directory under `C:/github/ecopunk/tools/poet-foundation/full-scope/`. Each worker creates a `HANDOFF.md` and `manifest.json` there, preserving any existing output and identifying its owner before editing. It does not write the shared register, another worker's directory or canonical shared files. The coordinator first checks existing assignments, current source and preimages, assigns exact file/symbol ownership, then integrates reviewed changes and owns shared module registration, manifests/locks, host/renderer/intent routing and serialized Cargo/native/GPU/checkpoint checks. The normal lease only coordinates cooperating callers and is not a system-wide lock.

Each handoff specifies the existing requirement and human/agent operation; actual current implementation, public owner, host/caller, tests and prior execution; exact source hashes and dirty state; proposed source/target files; positive, refusal and recovery cases; commands/process owner/result or `none`; source/output identifiers and evidence; remaining IDs and next action. The listed case is the first qualification slice, not a waiver of the rest of its governing capability. A discovered name or unreviewed file is not proof of a missing implementation. Follow [the adaptation guide](../../../planning/tech/poet-capability-adaptation-guide.md) and source notices.
