## Selected source-to-consumer traces

1. **Checkpoint and carrier.** [Poet checkpoint editor](C:/github/poet/native/src/graphical/checkpoints/editor.rs) delegates source-bound typed inspection, selected rig-resource access, compile and save through the checkpoint owner; its outer authorized host supplies access. [inspection.rs](C:/github/poet/native/src/graphical/checkpoints/inspection.rs) checks source stamp, saved source digest, package/key/resource digest and release policy around two canonical loads. The 16 MiB selected-resource cap is applied after whole-HMC load; it does not establish peak memory or per-resource rights. The latest signed rig test uses a synthetic non-GPU preview, not actual window or final package acceptance.
2. **Asset packaging and renderer.** [Core asset_package](C:/github/qualiaDB/crates/qualia-core-db/src/render/asset_package.rs) sorts compiled assets, verifies/deduplicates original encoded textures by SHA-256 and builds HMC entries; its texture resolver checks HMC index and MAT1 digest. [Webizen texture stream](C:/github/qualiaDB/crates/webizen-render/src/volumetric_hmc_stream.rs) implements generation-stamped request/apply over already retained bundle and asset bytes. Source tests exist; none executed in this pass. Prior [round 9](../../implementation-2026-10-26/round9/progress.md) and [post-update](../post-update-qualification/README.md) receipts qualify only their declared snapshots and workloads.
3. **Consumer boundary.** game-demo asset-review.js showLocalGraph checks a JSON source and separate Q42 header/digests, then displays the JSON claims; playLocalAnimation switches model frames. Generated rolling_commons_shell.js exposes HMC scene, mesh, Q42 and variant bindings. The generated interface alone does not prove the active scene uses reviewed Ecopunk artifacts or a native execution path. Trace and execute the selected game-demo → reviewed HMC → runtime entry with output and review evidence.
4. **Etalon and Aether.** Etalon render lib exports scene, volumetric, HUD and EMF APIs; Aether native manifest declares relevant renderer features. These are reusable source interfaces, not a specific frame, device interoperability or all-platform/film-quality qualification. The Etalon handoff preserves historical 299/299 tracker statements without treating the count as product acceptance.
