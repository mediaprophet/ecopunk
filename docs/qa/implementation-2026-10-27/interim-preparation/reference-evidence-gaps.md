## Prerequisite jobs that can start without code changes

1. **Tree reference packet:** curator selects a resolvable locality/referent scope and assembles a versioned, rights/terms annotated reference index (including image angles, source identifiers and unresolved traits); botanist reviews taxon and diagnostic evidence.
2. **Wallaby reference packet:** curator and zoologist select the corpus/specimen scope, record taxon-concept and locality evidence separately, then inventory available diagnostic, state, behavior and habitat sources with access/derivative conditions.
3. **Shared source-rights and review register:** rights steward records each candidate source's creator/authority, exact source/version, attribution, allowed access/use/derivatives, restrictions and reviewer status; flag unavailable or ambiguous permissions instead of assuming reuse. Apply the existing [semantic agreements and compensation handoff](../../../planning/tech/semantic-agreements-and-compensation.md) where contribution/obligation questions arise.

These jobs produce source/review evidence only. They do not authorize asset production or resolve unsupported claims.
