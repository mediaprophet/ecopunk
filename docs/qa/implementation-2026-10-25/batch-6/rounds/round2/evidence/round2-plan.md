Demonstrate source-to-output work by saving source and HMC, fresh-process reopen, regenerating the `.10d`, and verifying regenerated bytes against the saved output. Bind commands, logs, process outcomes, paths and hashes.
4. **Deferred; not executed.** Capture native preview PNGs only if required by an actual authoring/reopen workflow after foundation findings. Record byte count, SHA-256 and dimensions for each artifact. Keep baseline copies immutable under `baseline/`; do not overwrite them.

Tie observations to old/new image paths and hashes. Record improvement, unchanged, regressed, or unassessed; no visual change is inferred from a code diff.
