## Governance and reuse

The [implementation plan](../implementation-plan.md) is the single phase authority; the [existing job register](../biosphere-work-packets.json) remains the activation/ownership registry. Existing BSA/ECO/PA/FND/model IDs are preserved. These chapters add assignable detail, not a competing tracker or a blanket claim that current functionality is missing. Relevant older evidence is linked with its scope. New implementation must reconcile current source and later receipts before acting on historical gaps.

The user's latest corrections are binding in this proposal: the corpus covers the whole biosphere and its Earth/space environment; all sources retain namespace/provenance; inference uses existing QualiaDB logic; invalid values may receive separately recorded estimates through a declared, user-selected or user-defined method. Permitted private/proprietary/classified inputs are governed by existing access and release policies, including estimates and explanations. No mandatory universal median, private replacement store or hidden automatic grant of rights is introduced.

Scope includes all nine requested QualiaDB areas through existing reviews and chapter-specific owner traces: domains, modalities, solvers, specialized_libs, wgsl_forge, qualia-vision, qualia-audio, webizen-render and semantic_instruments, plus applicable sibling owners such as qualia-sim/geospatial. This is bounded source research; unreviewed code is not evidence of an absent capability.

No builds, tests, GPU runs, exports, acquisitions, paid calls, commits or publication were performed to produce this set. Local link/format/source-pin checks are documentation checks only. No species/package is declared complete.
