# Field Studio atlas

The website journey catalogue owns the driving waypoints, stops and stories. The atlas ontology records ecology references to its public Cotter and Tidbinbilla entries. Use public park evidence to plan habitat and species representation. Keep each source model with its taxon in Eco-intent.

For future observation maps, join Q42 facts on geography edition, level and area code before projecting WGS84 GeoJSON. Include the observation period, units, source and suppression status in statistics queries.
