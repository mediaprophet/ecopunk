# Historical implementation snapshots

These are byte-preserved before/after source images, tests, Cargo manifest snapshots and one-shot scripts from earlier implementation work. They are **not production crates or supported runnable workspaces**. Current production code belongs to its canonical Poet/QualiaDB owners. Current verification tooling is under `tools/poet-foundation/`.

The [Round 1–7 migration index](2026-10-25/batch-6/migration-index.json) maps 733 original documentation-folder paths to their archived bytes and SHA-256 pins. Historical receipts, manifests and reports remain under `docs/qa` unchanged; their original path strings describe the historical execution context. Use the [read-only resolver](../../tools/poet-foundation/round8/hygiene/resolve-archived-path.ps1) to find and verify a relocated file. Do not replay archived install/preparation/verifier scripts against current live source.

This migration covers one inventoried cohort. Older non-round staging under `docs/qa` remains for a separate dependency-reviewed cleanup; it is not claimed removed.
